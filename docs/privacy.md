# BGAV privacy policy

Effective November 26, 2026.

BGAV reads the GitHub Actions run page you open, including job names, statuses, durations, and dependencies. It processes that information in your browser to draw the workflow graph.

To show individual matrix jobs, BGAV requests job details from `github.com` over HTTPS. Your browser includes your existing GitHub session with these requests, as it does when you use GitHub. BGAV does not read or store your GitHub credentials.

BGAV keeps workflow data in browser memory while the run page is open. It saves your graph display preferences in Chrome's local extension storage. Uninstalling BGAV clears those preferences.

BGAV sends no workflow data or usage statistics to its developer and uses no analytics or advertising services. BGAV limits its use of information to displaying GitHub Actions runs in accordance with the Chrome Web Store User Data Policy, including the Limited Use requirements. [Chrome Web Store User Data Policy](https://developer.chrome.com/docs/webstore/program-policies/policies#limited-use)

For privacy questions, contact the developer using the email shown on the Chrome Web Store listing.
